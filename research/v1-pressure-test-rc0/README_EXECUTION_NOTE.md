# RC0 Execution Boundary

The hosted workflow is the experiment. Local or ad hoc results are not terminal evidence unless reproduced on the exact frozen research head by GitHub Actions.

The workflow subject is the published `v1.0.0` release tarball, not the research checkout. The research checkout supplies only harness code and evidence records.

If the hosted workflow fails, preserve the failing run before changing the harness. Classify the failure before deciding whether a rerun is justified.
