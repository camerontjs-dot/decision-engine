## Preserved deviations

### Run 1 — validator-loading and artifact-path apparatus failures

Run `34434075091` successfully regenerated the fresh CAL output, exact Contract B input, structural-shadow Contract C, and cross-validated the CAL C against the independently rebuilt B index. It failed before Decision evaluation because the matrix builder dynamically loaded the released validator without registering the module in `sys.modules`, preventing Pydantic from resolving postponed annotations.

The same run's artifact upload also rejected colon-bearing Contract B filenames under upload-artifact path compatibility rules.

Repairs:

- register the exact validator module before execution;
- package the build tree as a TGZ before artifact upload.

No semantic producer or maintained Decision code changed.

Disposition: apparatus failures; no Decision conclusion.

### Run 2 — evaluator conflated diagnostics with decision dependency

Run `34434298225` passed both producer setup and all 30 valid Contract C variant validations, then the v1 matrix evaluator reported failure on `contribution_channel_counterevidence` for the citation policy.

The maintained Decision policy had not actually changed its disposition, effect, or reason. Its diagnostics correctly echoed the changed contribution channel. The evaluator had defined its comparison signature to include diagnostics and therefore treated an observable diagnostic echo as a policy dependency.

The v1 evaluator was preserved. Successor `run_matrix_v2.mjs` separates:

- policy core: `evaluation`, effect, reason codes;
- diagnostics: recorded and compared separately.

Disposition: evaluator-design false positive. This failure is part of the evidence record.

## Inference

Within the bounded Contract-C-visible state surface tested here, the strongest current candidate shared machinery is not a CAL-specific decision abstraction. It is closer to:

1. exact semantic/assessment authority ingress;
2. exact target binding;
3. versioned policy selection;
4. policy-specific projection of a small authority-state slice;
5. deterministic `FAILED` / `HOLD` / `CLEAR` evaluation;
6. typed candidate effect on `CLEAR`;
7. canonical, authority-bound Decision output.

The matrix also shows that the current two policies consume different projections of the same semantic authority. Policy A cares about reported verdict and not basis membership. Policy B cares about basis membership and not reported verdict.

This supports, but does not prove, a producer-independent **authority-bound policy projection** primitive.

## Alternate explanations / limitations

- The structural-shadow producer is intentionally trivial.
- Only one natural same-input proposition was used.
- Fourteen of the 15 rows per family are validator-accepted counterfactual dependency probes, not demonstrated producer-reachable states.
- Equivalent Decision behavior may follow simply because the current policies are shallow functions over a small C subset. That still matters architecturally, but it is not evidence that all future policies share the same kernel.
- Contract C 1.0 itself remains normatively CAL-specific, so this result cannot justify admitting arbitrary non-CAL producers under that contract identity.
- The experiment did not test a genuinely different semantic domain such as release qualification, model evaluation, or agent-result verification.
- The current Decision ingress still does not close every possible Contract C internal-reference aperture merely by virtue of this matrix.

## Load-bearing assumption

The generalization hypothesis now depends most heavily on this assumption:

> a genuinely non-claim-audit assessment domain can preserve exact authority, target, execution/completion, causal-basis, and policy-projection semantics without forcing domain facts into misleading claim-audit vocabulary or requiring domain-identity branches in the shared Decision kernel.

## Falsifier / next discriminating test

Use a genuinely non-claim-audit assessment authority, preferably **research/release qualification** because it already has frozen, machine-verifiable evidence and naturally separates qualification from downstream promotion policy.

Do not label that authority Contract C 1.0.0 merely to make the experiment fit.

Create the smallest research-only generalized or sibling assessment-authority shape that can represent:

`exact candidate + exact qualification evidence + execution/completion + causal basis/residual + bounded assessment conclusion`

Then run at least two downstream Decision policies over the same assessment state. The producer-independent primitive hypothesis is weakened if the shared Decision machinery must branch on domain identity or if the supposed generic fields require metaphorical/ad-hoc translation to preserve semantics.

If the same ingress/target/policy/projection/evaluation/effect/output skeleton works without domain branching, that is substantially stronger evidence for extraction.
