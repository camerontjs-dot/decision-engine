# Valid CAL semantic variation -> Decision policy discrimination

## Classification

Draft Research Infrastructure / bounded integration experiment. No production authorization, merge, release, tag, promotion, Contract C/D change, Authorization, or execution.

## Exact base

Decision Engine `main`: `a4425f8eb47449ff6c683222921bbea9483742e2`.

## Parent evidence

Draft PR #41 established bounded real-output interoperability for two fresh CAL-produced `assessed / supported` Contract C objects. Both maintained Decision policies CLEARed on their respective supported-claim and causal-basis targets while exact binding/replay controls stayed closed.

This successor tests valid semantic variation rather than another positive repetition.

## Controlled intervention

Use the exact CAL Pipeline RC0 integration head `4b9d69936d8ecdbaac0217561be7a3a821b70522` and exact admitted evidence world.

For `PIPELINE_SMOKE_001:child:1`, the baseline target is:

`women < men`

The admitted evidence states that Women trailed Men by 11 percentage points, so the baseline CAL result is supported.

The experiment changes exactly the typed CAL target direction to:

`women > men`

It does not edit Contract C after production. CAL must construct and validate the resulting Contract C object itself.

Held fixed include the claim text, admitted evidence world, Evidence Bundler profile, CAL semantic machinery, and Contract B/C authorities.

This is a controlled research input intervention, not a world-causal counterfactual.

## Preregistered hypothesis

If CAL produces exact valid `assessed / contradicted` Contract C with the refuting contribution in the causal basis:

1. `decision-engine.contract-c.supported-claim-verification@1.0.0` should produce `completed / hold` with `contract_c_reported_verdict_not_supported`.
2. `decision-engine.contract-c.causal-basis-citation@1.0.0` should produce `completed / clear` for the exact deciding refutation contribution with `contract_c_contribution_in_causal_basis`.
3. Both Decision outputs must canonicalize under exact Contract D 1.0 authority.

This would demonstrate policy discrimination on one valid upstream state: a contradicted claim should not receive a verified-claim tag, while the exact evidence link responsible for the contradiction may still be citable as deciding evidence.

## Falsifiers

The experiment is not supported if:

- CAL cannot produce an exact valid contradicted Contract C from this controlled target change;
- the supported-claim policy CLEARs the contradicted claim;
- the causal-basis citation policy HOLDs the exact deciding refutation contribution despite its causal-basis membership;
- either output fails canonical Contract D validation;
- maintained source must be modified to obtain the expected distinction.

## Nonclaims

This experiment does not establish generic counterfactual reasoning, causal effects in the world, source legitimacy, corpus completeness, all Contract C state coverage, Authorization, or execution.
