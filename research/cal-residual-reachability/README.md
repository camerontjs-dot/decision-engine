# CAL residual/non-deciding contribution reachability -> Decision Engine

## Classification

Draft Research Infrastructure / bounded cross-stage reachability experiment.

No production authorization, merge, release, tag, promotion, Contract C/D change, Authorization, or execution.

## Exact Decision base

`camerontjs-dot/decision-engine` `main` at `a4425f8eb47449ff6c683222921bbea9483742e2`.

## Question

Can the current frozen CAL RC0 producer naturally emit a valid **assessed** Contract C proposition that simultaneously contains:

1. exactly one deciding causal-basis contribution; and
2. at least one retained residual/non-deciding contribution,

so that the maintained Decision Engine causal-basis citation policy can CLEAR the basis contribution and HOLD the residual contribution on the same CAL-produced Contract C object?

Do not hand-edit Contract C to manufacture the state.

## Structural observation to test

The exact frozen CAL RC0 runtime constructs a Contract C contribution only for `SUPPORTS` or `REFUTES` relations. Its categorical composition includes every support relation in the support basis and every refutation relation in the refutation basis. The Contract C projection emits an assessed single-necessary causal form only when exactly one contribution is in the internal basis. If multiple deciding contributions exist, the projection deliberately emits `not_checkable`, no `basis_members`, and puts all contributions into `residual_contribution_ids`.

That implies two discriminating cases:

- one `SUPPORTS` + one `IRRELEVANT`: assessed Contract C, one basis contribution, zero residual contributions because `IRRELEVANT` does not become a contribution;
- two `SUPPORTS`: two Contract C contributions exist, but projection becomes `not_checkable`, zero basis members, and both contributions become residual.

If both observations reproduce through the exact frozen producer, the desired assessed basis+residual shape is unreachable under current RC0 semantics.

## Falsifiers

The reachability hypothesis is falsified if the exact frozen CAL RC0 producer emits any assessed proposition with both a non-empty contribution basis and a non-empty residual contribution list for the tested structural cases.

The Decision-boundary hypothesis is falsified if a CAL-produced `not_checkable` multi-contribution object reaches the maintained residual-specific Decision reason before the proposition-completion HOLD, or if the maintained canonical Contract C integration fixture no longer reaches `contract_c_contribution_residual_non_deciding`.

## Bounded interpretation

This is a producer-shape reachability test, not a new CAL semantic experiment. The structural probe uses exact frozen CAL composition/projection code with explicit relation records so it isolates the load-bearing projection rule. It does not claim that the supplied relation records were independently generated by retrieval, measurement, or RC8J in this run.

The existing pipeline experiments already established that valid warranted `SUPPORTS` and `REFUTES` relations are individually reachable. This experiment asks what Contract C shape the frozen producer emits when more than one deciding relation is present.

If the assessed basis+residual shape is unreachable, the smallest next discriminating upstream change is not a Decision Engine change. It is a research-only CAL producer experiment that introduces an explicit, falsifiable rule for selecting one necessary basis contribution while retaining another deciding contribution as residual. Such a rule would be new causal/decision semantics and must not be smuggled in as formatting.
